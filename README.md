# TrustMed AI

## Overview

TrustMed AI is an Explainable and Trustworthy Healthcare AI System for Pneumonia Detection using Chest X-ray images.

The project uses:
- VGG16 Transfer Learning
- Binary Classification
- Grad-CAM Explainability
- ROC-AUC Evaluation
- Precision / Recall / F1-Score Analysis

---

## Problem Statement

Traditional healthcare AI systems often behave like black boxes.

TrustMed AI focuses on:
- explainability,
- reliability,
- trustworthy AI-assisted clinical support.

---

## Features

- Pneumonia vs Normal Classification
- Transfer Learning using VGG16
- Grad-CAM Explainability
- Confusion Matrix
- ROC Curve
- Precision / Recall / F1-Score
- Trust-aware AI workflow

---

## Model Architecture

- VGG16 (Pretrained on ImageNet)
- Global Average Pooling
- Dense Layer
- Dropout Layer
- Sigmoid Output
